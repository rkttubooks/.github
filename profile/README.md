# rkttu Books

남정현이 집필하고 관리하는 한국어 기술서와 실행 예제를 GitHub에서 제공합니다. 책마다 원고, 예제, 개정 이력을 판본별로 관리합니다.

## 첫 번째 책

《파일 하나로 시작하는 C#》 .NET 10판을 집필하고 있습니다. .NET 10 파일 기반 앱으로 C#을 배우는 과정을 다루며 원고와 예제를 함께 검토하고 있습니다.

## 읽기와 후원

도서별 원고의 제공 범위와 저장소 접근 조건은 해당 GitHub Sponsors 티어에 적습니다. 책 한 권을 대상으로 하는 1회 후원은 결제를 확인한 뒤 해당 판본의 비공개 저장소에 읽기 권한을 수동으로 부여합니다. 여러 책을 제공하는 월간 티어는 제공 체계를 마련한 뒤 공개합니다.
