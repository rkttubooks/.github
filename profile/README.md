# rkttu Books

rkttu가 집필하고 관리하는 기술서와 실습 자료를 이 조직에서 운영합니다.

## 준비 중인 책

**파일 하나로 시작하는 C# (.NET 10 판)**은 .NET 10 파일 기반 앱으로 C#을 배우는 과정을 다룹니다. 현재 원고와 예제를 비공개 저장소에서 검토하고 있습니다.

## 이용 안내

`rkttubooks`의 GitHub Sponsors 프로필은 승인 대기 중입니다. 후원 티어의 제공 범위와 저장소 접근 방법을 확정하면 이 페이지에 안내하겠습니다. 현재 후원을 통한 자동 접근은 시작하지 않았습니다.

저자와 공개 활동은 [rkttu의 GitHub 프로필](https://github.com/rkttu)에서 확인할 수 있습니다.
