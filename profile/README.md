# 남정현의 책

코드를 직접 실행하며 개념을 이해하고 필요할 때 다시 찾아볼 수 있는 한국어 기술서 컬렉션입니다.

소프트웨어 엔지니어이자 테크니컬 라이터인 남정현이 직접 집필하고 개정합니다. 책마다 원고와 예제를 같은 저장소에서 관리하여 설명을 읽은 자리에서 코드를 확인할 수 있습니다.

## 도서 컬렉션

### 《파일 하나로 시작하는 C#》 .NET 10판

C# 코드 한 파일을 실행하는 경험에서 출발합니다. 핵심 문법을 익힌 뒤 Minimal API, SQLite와 MCP 서버 예제로 활용 범위를 넓힙니다. 현재 원고를 집필하고 있습니다.

- [월간 후원으로 원고 읽기](https://github.com/sponsors/rkttubooks): 후원 기간 동안 이 책의 원고와 예제를 읽을 수 있습니다.
- [원고와 예제 저장소](https://github.com/rkttubooks/dotnet-fba-book-dotnet10): 초대를 수락한 GitHub 계정에서 목차와 실습 코드를 열 수 있습니다.

GitHub는 후원에 사용한 개인 계정을 책 저장소에 읽기 전용으로 초대합니다. 후원이 끝나면 저장소 접근도 종료합니다.

새 책이 준비되면 이 컬렉션에 추가하고 책마다 주제, 판본과 읽는 방법을 안내합니다.
