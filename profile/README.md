# rkttu Books

남정현이 집필하고 관리하는 한국어 기술서와 실행 예제를 GitHub에서 제공합니다. 책마다 원고, 예제, 개정 이력을 판본별로 관리합니다.

## 첫 번째 책

《파일 하나로 시작하는 C#》 .NET 10판을 집필하고 있습니다. .NET 10 파일 기반 앱으로 C#을 배우는 과정을 다루며 원고와 예제를 함께 검토하고 있습니다. [책의 원고와 예제 저장소](https://github.com/rkttubooks/dotnet-fba-book-dotnet10)는 비공개이며 접근 권한이 있는 계정에서 열립니다.

## 읽기와 후원

《파일 하나로 시작하는 C#》 .NET 10판의 월간 단권 후원 티어를 [GitHub Sponsors](https://github.com/sponsors/rkttubooks)에 공개했습니다. GitHub는 후원 중인 개인 계정을 책 저장소에 읽기 전용으로 자동 초대하고, 후원이 끝나면 접근을 종료합니다. 기존 베타 리더의 무료 직접 초대는 현재 책 저장소에만 적용합니다.
