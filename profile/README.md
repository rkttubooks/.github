# 남정현의 디지털 책방

남정현이 개발자를 위한 한국어 기술서를 집필하고 개정합니다. 정식 전자책 출간과 GitHub 기반의 지속적인 집필을 함께 진행합니다. 후원금은 자료 조사, 예제 실행 검증과 원고 교정에 사용합니다. [GitHub Sponsors](https://github.com/sponsors/rkttubooks)에서 참여할 수 있습니다.

## 정식 전자책과 최신 원고

정식 전자책은 출간 시점의 내용을 검수하고 편집한 완결된 Release 판본으로 교보문고 e퍼플을 통해 판매합니다. 멤버십 가입 없이도 해당 판본의 내용을 모두 읽고 실습할 수 있습니다. 첫 책은 출간 준비 중이며 구매 링크는 출간 후 안내합니다.

GitHub Sponsors에서는 `남정현의 디지털 책방 Founding Member`를 월 5달러로 운영합니다. 현재 집필 중인 도서의 최신 원고, 개정 내용, Early Access 챕터, 추가 예제와 보충 자료를 Continuous Edition으로 제공합니다. 향후 새 도서의 진행 중 콘텐츠도 같은 멤버십에 포함합니다. Continuous Edition은 최신 내용을 반영하며 계속 수정하는 작업판입니다.

출간된 모든 전자책 파일을 무료로 제공하는 서비스로 운영하지 않습니다. 기본 멤버십에 무제한 AMA나 개별 응답 시간은 포함하지 않습니다.

## 하나의 멤버 저장소

개인 GitHub 계정으로 Founding Member 등급을 후원하고 [rkttubooks-members](https://github.com/rkttubooks/rkttubooks-members)의 읽기 전용 초대를 수락하면 `books/`에서 원고를 읽을 수 있습니다. 책이 늘어나도 같은 저장소를 사용합니다. 내부 집필 자료와 출판 도구는 저자용 저장소에서 별도로 관리합니다.

후원이 끝나면 멤버 저장소 접근은 종료합니다. 적법하게 내려받은 사본은 개인 학습용으로 계속 이용할 수 있으며 원본 재배포 권한은 부여하지 않습니다. [공통 멤버십 이용 조건](https://github.com/rkttubooks/.github/blob/main/SUBSCRIPTION_TERMS.md)에서 자세한 범위를 안내합니다.

## 첫 번째 도서와 공개 자료

《파일 하나로 시작하는 C#》 .NET 10판은 `.cs` 파일 하나에서 시작해 C# 문법, Minimal API, 데이터 연동, AI 코드 검토와 MCP 서버 제작을 실습합니다. 현재 이 책의 최신 원고를 먼저 제공합니다.

[공개 예제, 정오표와 변경 이력](https://github.com/rkttubooks/dotnet-fba-samples)은 멤버십 가입 없이 사용할 수 있습니다. 책에서 다루는 MCP 실습은 포함하지만 호스팅 MCP 서비스는 제공하지 않습니다.
